# FloatDraft テスト方針

## 自動（毎回）
```bash
scripts/verify.sh          # 全項目（各マイルストーンの完了条件）
scripts/verify.sh --quick  # 開発中の高速確認: プロジェクト生成、Debug ビルド、テスト
```
| 確認項目 | 方法 |
|---|---|
| ビルド（Debug / Release） | `xcodebuild`。警告は 0 件（`SWIFT_TREAT_WARNINGS_AS_ERRORS` とログの検査） |
| ユニットテスト | Swift Testing（`FloatDraftTests`。アプリをホストにして実行） |
| Universal Binary | Release 版で `lipo -archs` に arm64 と x86_64 が含まれる |
| Info.plist | バンドル ID、`LSUIElement`、`LSMinimumSystemVersion`、PrivacyInfo の同梱 |
| Entitlements | Release 版の署名に含まれる権限が `com.apple.security.app-sandbox` **だけ**であること |
| 禁止 API | バイナリ（`nm -u`）とソース（grep）の両方で、アクセシビリティ、イベントタップ、入力監視の API がないこと |
| クリップボード | ソース中にクリップボードの読み取りがないこと（E18） |
| Release 版の中身 | アイコン、`ja.lproj`、App Intents のメタデータがあること。リソース束に署名が残っていないこと。Debug 用フックが含まれないこと |
| 翻訳 | String Catalog とコードの文字列が一致し、すべてに日本語訳があること。App Shortcut のフレーズも同様 |
| ツールチップ | パネルのビューで `.help` を使っていないこと |

### ユニットテストの方針
UI に依存しないロジックは純粋関数として切り出してテストする。`TestSupport` の `TestEnvironment` で UserDefaults とクリップボードを隔離する（実ユーザーのクリップボードに触れない）。
- **M2**: パネルの配置計算（複数画面、反転、クランプ、保存したフレームの画面が外されたとき）、トグルの状態遷移
- **M3**: キーの振り分け。NSTextView をテスト内で生成し、`setMarkedText(_:selectedRange:replacementRange:)` で変換中の状態を作る。その状態で `insertNewline:`、`cancelOperation:`、⌘Return を送っても、コピーも非表示も**起きない**ことを確認する。確定状態では起きることも確認する
- **M4**: 整形の変換（引用トグル、フェンスの長さ、空行の圧縮、CRLF と U+2028 の扱い）、Undo で整形前に戻ること、文字数カウント（絵文字、結合文字、全角スペース）、履歴の上限とピン留めの扱い（外した項目が消えないこと）、履歴ファイルの互換性（1.0.0 の形式を読めること、読めないファイルを上書きしないこと）
- **追加機能**: 外部テキストの追加（下書きが空白だけなら置き換え、それ以外は改行して末尾に追加、空白だけのテキストは無視、変換中は拒否、1回の Undo で戻る）、サービスの処理がシステムから渡されたペーストボードだけを読むこと、App Intents の実行結果、呼び出しフレーズの日本語訳（verify.sh）

## 動作確認の手段
```bash
open build/DerivedData/Build/Products/Debug/FloatDraft.app
open -n build/DerivedData/Build/Products/Debug/FloatDraft.app --args -showPanelOnLaunch   # Debug のみ: 起動時にパネルを表示
  # 追加で -overlay history / -overlay quickSettings を付けるとオーバーレイも開く。-showSettingsOnLaunch は設定ウィンドウ
```
キー入力の自動送信（System Events など）にはアクセシビリティ権限が要るので使わない。表示位置は `CGWindowListCopyWindowInfo` で、見た目は `screencapture -l <windowID>` で確認できる。

## 手動チェックリスト（実機確認。マイルストーンごとに該当する項目）

### M2 パネル
- [ ] ⌃⇧Space で、カーソルの 20pt 下にパネルが開く
- [ ] 画面の下端近くでは上側へ反転し、右端と左端ではクランプされる
- [ ] 外部ディスプレイ上でも、カーソルのある画面に開く
- [ ] フルスクリーンのアプリの上にも表示される
- [ ] ヘッダーとステータスバーでドラッグ移動できる。エディタ内のドラッグではテキストが選択される
- [ ] 記憶モードでは、ドラッグした位置に開く。そのディスプレイを外すと、表示中の画面内に開く
- [ ] ⌘A / C / V / X / Z / ⇧⌘Z がビープ音なしで動く
- [ ] パネルを表示中にメニューバーアイコンをクリックすると閉じる（開き直さない）

### M3 IME（ことえり＋ライブ変換、Google 日本語入力、ATOK で確認）
- [ ] 変換中の Return は確定だけで、改行もコピーも起きない
- [ ] 変換中の Esc は変換の取り消しだけで、**パネルは閉じない**
- [ ] 変換中の ⌘Return でコピーされない
- [ ] 確定後の Return は改行になる
- [ ] 確定後の ⌘Return でコピー → パネルが閉じる → 元のアプリの入力欄で ⌘V すると貼り付けられる
- [ ] Esc で閉じて再び開くと、テキストとカーソル位置が残っている
- [ ] パネル外の別アプリをクリックすると、**そのアプリにフォーカスが残る**（D1）
- [ ] 入力中に三本指スワイプ（または ⌃← / ⌃→）で操作スペースを切り替えても、パネルは切り替え先で表示されたままで、そのまま入力を続けられる。戻っても同じ
- [ ] 設定で「操作スペースを切り替えてもパネルを閉じない」をオフにすると、切り替えで閉じる
- [ ] ⌘Tab で別のアプリに切り替えると、一呼吸おいてパネルが閉じる
- [ ] スマート引用符、ダッシュ、インライン予測が発生しない

### M4 機能
- [ ] 整形の 3 機能が ⌘Z で元に戻る。ボタンを押した後もそのまま入力を続けられる
- [ ] 履歴の検索（日本語）、復元（⌘Z で元に戻せる）、ピン留め、31 件目で一番古いものが消える（ピン留めは残る）
- [ ] 不透明度 50% でも文字は 100% で表示される
- [ ] ログイン時起動の ON/OFF（/Applications に置いたビルドで確認）
- [ ] 初回起動時にオンボーディングが表示される（画面中央）。「Try It Now」でパネルが開く。閉じた後は次回から出ない
- [ ] 整形のショートカット ⌘⇧. と ⌘⇧K が効く。変換中に押しても何も起きない
- [ ] ⌘Y（または時計アイコン）で履歴がエディタの右に開き、パネルが広がる。検索欄にフォーカスが入る。日本語で検索して、変換中の Return と Esc は確定・取り消しだけ
- [ ] 履歴の検索欄で、確定後の Return は先頭の候補を復元し、Esc はエディタにフォーカスを戻す（サイドバーは開いたまま）。次にパネルを開いたときもサイドバーの開閉状態が保たれる
- [ ] クイック設定（スライダーのアイコン）を開いて Esc で閉じる。もう一度 Esc でパネルが閉じる
- [ ] 再コピーボタン、およびメニューバーの右クリックメニューの「Re-copy Last」で、直前のテキストがクリップボードに戻る
- [ ] パネルを閉じたままメニューバーから「Re-copy Last」を選ぶと、コピー完了の表示がマウスのある画面の中央に出る（起動直後や、前回パネルを開いた画面と別の画面でも）
- [ ] ステータスバーの文字数が、絵文字や濁点の付いたかなを1文字として数える
- [ ] 見えない文字（例: ゼロ幅スペース）を含む文を貼り付けると、ステータスバーに「見えない文字 N」が出る。クリックで取り除かれて警告が消え、⌘Z で戻る。絵文字（👨‍👩‍👧、🏴󠁧󠁢󠁥󠁮󠁧󠁿）や異体字（葛󠄀）だけでは出ない

### 追加機能（サービスメニュー、ショートカット.app）
- [ ] テキストエディットなどで文字を選択し、アプリメニュー › サービス ›「FloatDraft で編集」で下書きに追加され、パネルが開く（初回はサービス一覧への反映に再ログインや `/System/Library/CoreServices/pbs -update` が必要なことがある）
- [ ] 下書きが空でないときは改行して末尾に追加され、⌘Z 1回で追加前に戻る。空のときはそのテキストだけになる
- [ ] パネルで日本語を変換中にサービスを実行しても、変換中の文字が壊れない（追加されず、パネルが前面に出るだけ）
- [ ] ショートカット.app に FloatDraft のアクションが3つ表示され、日本語名で出る
- [ ] 「下書きにテキストを追加」「下書きパネルを開く」が動く。「直前にコピーしたテキストを取得」が、最後に「コピーして消去」したテキストを返す
- [ ] Siri / Spotlight からの呼び出しフレーズ（日本語）でアクションが見つかる

### アプリアイコン
- [ ] Finder、「FloatDraft について」、設定ウィンドウでアイコンが表示される（Finder に古いアイコンが残るときは Finder を再起動する）
- [ ] システム設定 › 外観 のアイコンのスタイル（デフォルト・ダーク・色付き・クリア）を切り替えると、それぞれの見た目で表示され、パネルと鉛筆が見分けられる
- [ ] macOS 14〜15 では平面のアイコンで表示される（確認できる環境があれば）

### テーマ
- [ ] クイック設定でテーマを切り替えると、その場で配色が変わる（ペーパーが既定）
- [ ] ライト／ダークモードを切り替えると、グラファイト以外のテーマが追従する
- [ ] どのテーマでもヘッダーのアイコンがはっきり見え、オンの状態（ピン留め・履歴・設定）が背景色で分かる
- [ ] 不透明度 50% でも、どのテーマでも文字がはっきり読める

### 使い勝手の改善
- [ ] ⌥⌘Return（またはステータスバーのコピーボタン）でコピーされ、本文とパネルはそのまま残る。変換中に押しても何も起きない
- [ ] 下書きが空のとき、エディタに操作ヒントが薄く表示され、1文字入力すると消える
- [ ] 履歴の検索欄で ↑↓ で行が選択され、選択した行が見える位置までスクロールする。Return で置換、⌥Return で挿入
- [ ] 行の ⌥クリックでカーソル位置に挿入される。どちらの操作も ⌘Z で戻る
- [ ] ⌘1〜⌘9 で、上から N 番目のピン留め（行に ⌘N と表示）がカーソル位置に入る。変換中は何も起きない
- [ ] ⌘+ / ⌘− / ⌘0 で文字サイズが変わる。設定ウィンドウで等幅フォントに切り替えられる
- [ ] VoiceOver で、ヘッダーとステータスバーのアイコンボタンが名前で読み上げられる
- [ ] ヘッダー・ステータスバー・履歴のアイコンにマウスを0.5秒ほど乗せると、機能の説明が表示される。クリックやキー入力、マウスを離すと消える
- [ ] 履歴の「ピン留め以外を消去」を押すと、サイドバー下部に確認が出る。キャンセルでは何も消えず、削除でピン留め以外が消える。確認中もパネルは閉じない
- [ ] 設定 › 外観 › 表示モードで「ライト」「ダーク」「端末に合わせる」を切り替えると、パネル・設定ウィンドウ・ツールチップがそれに従う（グラファイトのテーマは常にダーク）
- [ ] クイック設定の「詳細設定…」「完了」、履歴の「ピン留め以外を消去」が、マウスを乗せると色が濃くなり、ボタンだと分かる
- [ ] クイック設定から「詳細設定…」（または ⌘,）で設定ウィンドウを開き、閉じると、同じ位置・同じ画面のパネルに戻る。パネルを開いていなかった場合は、元のアプリに戻る
- [ ] ライトモードでグラファイトを選んでも、クイック設定のほかのテーマの見本はライト版のまま表示される
- [ ] グラファイトで下書きを空にしてから、履歴の復元・ピン留めの挿入（⌘1）・サービスメニューで文字を入れても、文字が黒くならず読める
